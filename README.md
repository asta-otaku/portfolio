# asta-otaku — Portfolio

Frontend engineer portfolio for Ibrahim Afolabi.

## Stack

- Next.js App Router
- Tailwind CSS + Framer Motion + Lenis
- Static content in `content/site.ts` (no database)

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```
